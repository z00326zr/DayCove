# 拾日匣 · DayCove

英文名 **DayCove**，缩写 **DC**。A home for your days.

本地优先的个人日记桌面客户端。最终交付为 macOS / Windows 独立软件，双击应用或快捷方式启动；不需要浏览器、账号、Node.js 或服务器。

## 开发与构建

开发环境需要 Node.js 22.13+（建议 Node.js 24）。

```sh
npm ci
npm start
```

`npm start` 构建页面后直接启动 Electron。`npm run dev` 仅为浏览器开发预览，预览数据使用 localStorage，与桌面日记库分开。

```sh
npm test
npm run build
npm run pack:mac
npm run pack:win
```

Mac 上构建 DMG，Windows 上构建 NSIS 安装程序，产物在 `release/`。`npm run pack:dir` 只生成应用目录。发布分发需自行配置平台代码签名及 macOS 公证；本地验收构建尚未签名/公证。应用图标已生成，修改 SVG 后运行 `npm run icons` 更新。

## 当前功能

- 我的轨迹：离线年度全国地图，日记地点可选省、市或区县；地点收藏、归属地与历史快照，完整备份一并迁移。
- 日记、周记、随笔；日期空间、地点、天气、标签与全文匹配搜索。
- Tiptap 可视化排版、Markdown 源码、实时对照预览；图片插入、撤销重做。
- SQLite 本地存储，事务写入、WAL 日志、只更新变化记录。
- 图片独立存入附件目录，按 SHA-256 命名去重，单张最大 8 MB。
- 自动保存、回收站恢复、专注写作、原生桌面菜单和快捷键。
- 完整备份包含附件；导入校验，重复跳过、冲突保留副本；重复导入相同冲突备份不会再次生成副本。
- 启动与每小时自动备份，保留最近 30 份自动快照；导入前另存当前库。
- 启动密码、首次设置提示、以后不再提示偏好，以及配置中的设置/修改/关闭。
- 可扩展配置面板：写作偏好、地点与归属地、密码与安全、数据与备份、关于；字体、字号、行距、正文宽度与启动编辑模式持久保存。
- 应用内离线 [使用说明书](public/manual.html)。页面不常驻展示教程与技术说明。

## 数据位置与迁移

桌面日记库位于 Electron userData 目录，通常为：

- macOS：`~/Library/Application Support/ediary-plus/`
- Windows：`%APPDATA%/ediary-plus/`

```text
library.sqlite      正文、Markdown 源码、日期、标签及回收站
attachments/        按内容哈希去重的图片文件
security.json       启动验证器与提示偏好
preferences.json    写作偏好
backups/            自动备份、导入前备份、旧库迁移前备份
```

SQLite 开启 WAL 时会有 `library.sqlite-wal`、`library.sqlite-shm` 辅助文件。不要仅复制运行中的数据库主文件作为完整备份；请使用“备份日记库”。

旧 `library.json` 首次打开时先创建完整备份，再导入 SQLite，原文件保留且只迁移一次。备份 `.ediary` 继续兼容第一版格式，导出时会将附件嵌入便携包，换电脑导入后重新分离图片。密码配置不随备份迁移。

## 安全边界

密码使用 PBKDF2-HMAC-SHA256、600,000 次迭代、16 字节随机盐、32 字节派生值，不存明文。错误尝试增加等待时间。配置损坏拒绝打开，不会静默降级为免密模式。

主进程独占文件访问；渲染进程开启上下文隔离、沙箱，关闭 Node.js 集成，通过有限 preload API 调用主进程。IPC 验证来源主窗口与解锁状态，附件协议限制为哈希文件名并检查解锁状态。外部窗口、导航和权限请求被阻止。

启动验证保护应用访问，**日记库、附件与备份仍为明文**。拥有本地文件权限的人可以绕过应用锁。目前没有应用内密码找回、内容加密、数据目录切换、自动跨设备同步或 `.edf` 兼容导入。

## 覆盖安装与自动沿用数据

从 0.2.4 开始，程序名称固定为 eDiary Plus，Windows 的安装 GUID、目录与快捷方式固定；安装新版覆盖程序文件，不再设计为多版本并存。发布归档仍按 release/版本 分目录。日记、附件、密码和写作配置存放在独立的 appData/ediary-plus，安装及卸载均不删除用户数据。

首次启动新版时，先只读生成 before-upgrade 完整备份（含图片），成功后打开现有库并沿用全部记录，无需手动导入。有效的现有库始终优先，不会被旧备份覆盖。只有 library.sqlite 与旧 library.json 都缺失时，才自动从最新有效的本地完整备份恢复；备份均无效则报错，不静默创建空库。数据库存在但损坏时停止打开，不自动覆盖损坏文件。

此处是本地覆盖安装及数据衔接，不是联网自动下载安装器。macOS 将新版同名应用复制到原位置替换；Windows 使用固定身份安装程序升级。0.2.3 曾采用版本化程序名称和独立安装身份，若已安装该特殊版本，需移除旧程序一次再使用固定名称新版，保留用户数据目录。不会擅自删除历史程序文件。

温度控件与新记录温度字段已移除，历史记录里的旧温度数据保留兼容；字色与底色作为富文本样式保存，Markdown 使用内联 HTML 保存颜色及嵌套加粗/斜体，完整备份保留原始内容。


## 0.2.5 写作与备份管理

可拖动导航/列表右侧边界调整宽度；聚焦边界后可用左右方向键、Home/End 调整。顶部可收起列表，专注写作隐藏两栏。布局在本机记忆，不改变日记内容。工具栏自动换行，保存状态显示最后成功时间；失败时可重试。

配置 → 数据与备份可以立即生成本地完整备份、查看列表和最近执行结果、打开目录。列表恢复和外部导入均校验备份后显示篇数及日期范围，确认后先备份当前库再合并，保留冲突副本。自动快照启动时及每小时生成，自动快照保留 30 份，手动/升级/导入前快照不自动清理。外部“另存为”导出不列入本地快照状态。软件关闭时没有后台定时任务。

历史修订、日记/备份内容加密不包含在此次更新中。启动密码仍只保护应用访问，不代表内容加密。


## 品牌名称与旧版升级

0.2.6 起展示名称为“拾日匣”，品类说明为“本地日记本”。Logo 将书页与收藏匣结合，圆点象征每天的日光；不使用锁或盾牌暗示内容加密。`public/logo.svg` 是矢量源文件，运行 `npm run icons` 生成桌面图标。

原 eDiary Plus 的 appId、Windows 安装 GUID、appData/ediary-plus 数据位置、浏览器存储键、附件协议与 .ediary 备份格式均保持兼容；名称改变不迁移或重置日记、附件、安全及写作配置。

Mac 首次品牌升级：退出旧程序，将原 eDiary Plus.app 改名为拾日匣.app，再复制新版并选择替换。后续直接替换同名应用。Windows 使用原 GUID 查询已有 InstallLocation，沿用原安装路径；软件及快捷方式展示新名称，实际覆盖安装仍需 Windows 实机验收。0.2.3 特殊独立安装版仍需一次性移除旧程序，保留数据。


## 0.2.7 保存节奏

输入只标记未保存修改；每分钟的 00、10、20、30、40、50 秒触发保存，未修改时不写入。定时器每次按系统时间重新计算边界，休眠或事件循环延迟后恢复对齐，不追补重复写入。顶部“保存”、Command/Ctrl+S、原生文件菜单保存均立即写入。备份/原生 Markdown 导出/恢复前先写入待保存修改。等待定时保存、写入中或保存失败时均保留关闭保护。写入采用不可变快照及串行队列，保存旧快照不能清除期间的新修改。


## 0.2.8 保存图标

人工保存入口移到编辑模式栏右端，使用无文字磁盘图标，三个模式位置一致。悬停/聚焦显示快捷键；待保存圆点、写入中圆环、完成勾号及错误警告辅助区分状态。提供保存无障碍名称、键盘操作和减少动画支持。顶部保留保存状态文字，整 10 秒自动保存策略不变。


## 0.2.9 标签交互

标签块支持回车/中英文逗号确认、批量粘贴、单个移除、去重和已有标签推荐。支持方向键选择、Enter 确认、Escape 收起。输入草稿同步到当前记录并参与整10秒保存，避免未按回车时丢失；确认后才在列表显示成标签块。

点击标签可跨日期和类型筛选未删除记录，并清除原搜索条件。列表显示当前标签和清除入口；“标签”面板提供标签目录及使用篇数。进一步搜索可与标签筛选组合。旧 tags 字符串不做启动迁移，解析时兼容中英文逗号、分号、顿号和换行，编辑后继续按字符串存储，备份格式和 schema 不变。全局标签重命名/批量删除不在本次范围。
