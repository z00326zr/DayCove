# 我的轨迹：地点标注与数据约定

## 当前口径

- 我的轨迹只展示日记中实际记录过的地点，按所选年份在全国地图上标注，可选到省、市或区县。
- 相同级别的同一地点无论记录多少篇日记只标注一处，标注关联对应日记 ID，供后续查看原文。
- 不统计到访次数、出差次数、停留天数或出差天数，不推断连续行程、返回日期及漏写日期的所在地点。此前关于这些统计的约定全部取消。
- 只使用所选年份的实际日记地点，不将跨年记录之间的空白日期补成足迹。
- 仅未删除的日记参与标注；周记和随笔不用于推断足迹。未设置归属地、归属地内的地点同样正常标注。
- 旧日记的自由文本地点保留，不猜测所属区县或坐标；用户选择任一级结构化地点后才能加入地图。

## 归属地与地点

- 地点为省、市、区县的代码和名称组合，日记地点可选到省、市或区县。
- 归属地可选省、市或区县；所选范围内的子级算本地，记录精度不足时保留未知。
- 每篇新日记创建时复制当时的归属地为 `homeSnapshot`，实际地点独立存为 `place`。以后修改设置不得重写历史快照。
- 未设置归属地时归属关系为未知，不自动算作外地；不影响足迹标注。
- 常用地点支持三级精度，按实际级别和代码去重。

## 0.2.10 实现

- 侧栏入口与独立年度地图视图已接入；区县着色及圆点、缩放平移、年度切换、地点与原日记跳转、待完善地点列表。
- `src/place-picker.js` 和 `src/regions.js` 提供省市区级联与收藏；配置新增“地点与归属地”。历史快照可在日记信息区单独选择，旧记录不自动套用现有归属地。
- `data.places`（归属地、收藏）写入 SQLite metadata 的 places 键；`place`、`homeSnapshot` 随每篇日记 JSON 保存。写入保持同一事务，完整备份包含这些字段，schema v1 不变。
- 导入合并保留已有地点配置的归属地，收藏按区县代码去重；没有配置的目标库采用备份配置。旧备份不清空新配置。
- 地图离线延迟加载；来源、许可、区划版本和覆盖限制写入使用说明书及 `public/licenses/`。当前选择目录覆盖内地与香港；台湾区县和澳门堂区数据未提供。无边界的区县保留列表，不猜测坐标。
- `scripts/prepare-geography.mjs` 从来源 GeoJSON 生成 SVG 路径数据，保留原始文件 SHA-256；不设区县的城市使用全市边界。
- `tests/trajectory.test.mjs` 验证标注口径；`tests/places-library.test.mjs` 验证级联目录、历史快照、旧库升级、完整备份迁移和合并。

## 0.2.11 渲染优化

- `src/atlas-renderer.js` 使用 Canvas2D、设备像素比、Path2D 缓存和逐帧合并绘制；以空间索引剔除视野外县域。
- 省界与省名默认展示；相对全国视图300%及以上才显示县域边界，900%及以上显示可容纳的区县名称。地点标记始终保留，地名避免互相遮挡。
- `src/data/map.json` 包含同源省界及基础区县路径；更高精度区县路径位于延迟加载的 `map-detail.json`，不在缩放过程中重建全量SVG节点。两级路径均来源于原始GeoJSON，来源校验值保留。
- `src/map-viewport.js` 提供坐标变换、指针锚点缩放、缩放范围与空间索引；测试覆盖长宽比变化、300%阈值、小区县定位和可见区域检索。
- 滚轮缩放以指针为中心；连续点击按钮累积缩放目标，动画尊重减少动态效果偏好。拖动、键盘和全国复位共用视口模型。
- 无日记数据或数据库结构变更；绘图验收样例只使用独立测试地点。

## 0.2.12 三级地点

- `place.city` 和 `place.county` 可为空。只选省时二者均为 null，选市时 county 为 null；禁止没有市却带区县等不一致组合。旧记录继续有效，schema v1 不变。
- `placeKey`、`placeName`、`placeLevel` 统一地点身份与最具体名称；2、4、6位代码分别代表省、市、区县，相同范围不同精度不自动合并。
- 地点选择器在每级可确认和收藏；切换上级清空下级。归属地、历史快照共用同一选择规则。
- `map.cities` 增加同源市级边界；`src/map-places.js` 为三级地点建立索引，直辖市市级使用相同省级范围，省直辖县级组合使用实际县域组合，不以任一县代替整个市级组合。
- 轨迹显示所选范围，省市级足迹不会生成所有子区县记录；县界仍须300%才显示。日记、快照、收藏在SQLite和备份中保持原精度。
- 记录省与归属地市同省但无法确定城市，或记录市与归属地区县同市但无法确定区县时，`isLocal` 返回 null。
- 三级验证、聚合、地图索引、旧库升级和备份往返测试位于 `tests/place-levels.test.mjs`。
