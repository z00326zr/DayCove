# 拾日匣

- 英文名：DayCove；英文缩写：DC；英文标语：A home for your days.
- 名称：拾日匣，读音 shí rì xiá。
- 品类说明：本地日记本。
- 宣传语：收好每一天，留给未来的自己。
- 界面、窗口、菜单和桌面应用使用完整中文名称，不缩写成“拾日”，不添加 Plus 或 ++。
- 图形：浅色书页收入收藏匣；右上日光圆点代表被珍藏的每一天。避免增加锁、盾牌或使用内容已加密的宣传。
- 主色：深青 #245F65；辅助色：浅薄荷 #C7E7DD、纸白 #F7FAF8、日光 #E7C88C。
- 矢量源：public/logo.svg；图标：build/icon.png、build/icon.icns、build/icon.ico。运行 npm run icons 重新生成各平台图标。
- 保持比例及四周留白，不拉伸、重着色或在图标内叠加名称。页面品牌字号 21px，图形宽高 36px。

0.2.6 品牌升级仅修改展示和图标，保留历史技术标识、Windows GUID、原数据目录及备份协议以兼容已有数据。Mac 首次更名升级的替换步骤见使用说明书。
